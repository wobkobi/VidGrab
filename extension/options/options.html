⬇️Default download

The main Download button uses these. The panel arrow starts from them too, so the audio choices apply when you switch it to Audio.

Max size fits a video under an upload limit, such as Discord's or WhatsApp's, and always saves MP4. Converts to fit when no stream is small enough (slower, lower quality).

🧩Advanced: page selectors

Change these only if YouTube moves its buttons and the Download button disappears.

Each field takes one selector, or several separated by commas. Copy any of these into a field or remove one, then click Save. Open YouTube tabs update straight away.

Watch page button container

#top-level-buttons-computed default
The row with Like, Share and the other buttons under the video.
ytd-watch-metadata #actions #top-level-buttons-computed
The same row, only inside the video's title and channel block, so look-alikes elsewhere on the page are skipped.
ytd-menu-renderer #top-level-buttons-computed
The same row, found through the menu that holds it and the three-dot button.
#actions-inner #menu
That whole menu, three-dot button included. For when the row itself has moved.
ytd-watch-metadata #actions
The whole strip of actions beside the channel name. The widest choice, so the button may land at its far end.

Shorts action bar

#actions.ytd-reel-player-overlay-renderer default
The column of buttons beside a Short: Like, Dislike, Comments and Share.
ytd-reel-player-overlay-renderer #actions default
The same column, found from the Short's overlay.
reel-action-bar-view-model
The action bar in YouTube's newer Shorts layout.
#button-bar
A button bar some Shorts layouts use. The broadest choice, so try it last.

Combining selectors

With a comma list the button goes in whichever match comes first on the page, top to bottom, not in the order you typed them. So list alternatives for the same spot, where only one is likely to exist at a time.

For example, the Shorts default names the same column two ways, so it still works if YouTube changes one:

#actions.ytd-reel-player-overlay-renderer, ytd-reel-player-overlay-renderer #actions

Adding the newer bar on the end covers both Shorts layouts, since a Short has one or the other:

#actions.ytd-reel-player-overlay-renderer, ytd-reel-player-overlay-renderer #actions, reel-action-bar-view-model

Don't list a box together with something inside it, such as #actions-inner #menu with #top-level-buttons-computed. The outer box always comes first, so it always wins.

Reset selectors puts the defaults back. When nothing you entered matches, the add-on still tries the lists above by itself.
